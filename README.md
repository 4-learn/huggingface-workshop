# Hugging Face Workshop

模型層（Model Responsibility）的 Workshop 解答。

## 目錄

| 目錄 | 說明 |
|------|------|
| `model_basics/` | 模型基礎：分類、生成、搜尋 |

## 安裝

```bash
pip install transformers torch sentencepiece huggingface_hub
```

## 執行

```bash
# 模型基礎 Workshop
python model_basics/solution.py
```

## 注意事項

- 完整版需要下載模型（約 1-2GB）
- 簡易版使用規則，不需下載模型
- 建議先用簡易版測試，確認邏輯正確後再跑完整版
